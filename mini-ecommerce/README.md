# Shopwave

A product listing interface powered by the [FreeAPI](https://freeapi.app) Products API.

## Features
- Product card grid (image, brand, title, rating, price)
- Discount badge with struck-through original price
- In-stock / low-stock indicator
- Debounced search & pagination
- Loading skeletons, error & empty states

## API
`https://api.freeapi.app/api/v1/public/randomproducts`

## Stack
React 19 · TypeScript · Vite · Tailwind CSS v4

## Run
```bash
pnpm install
pnpm dev
```
