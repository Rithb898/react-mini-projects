# Daily Jokes

A jokes viewer powered by the [FreeAPI](https://freeapi.app) Random Jokes API.

## Features
- Featured joke viewer with a "Next joke" button (auto-loads next page)
- Full joke card grid with category chips and copy button
- Debounced search & pagination
- Loading skeletons, error & empty states

## API
`https://api.freeapi.app/api/v1/public/randomjokes`

## Stack
React 19 · TypeScript · Vite · Tailwind CSS v4

## Run
```bash
pnpm install
pnpm dev
```
