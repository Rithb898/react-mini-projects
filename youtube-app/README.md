# VideoTube

A YouTube-style video listing UI powered by the [FreeAPI](https://freeapi.app) Videos API.

## Features
- Responsive video card grid (thumbnail, duration, title, channel, views, age)
- Debounced search
- Pagination
- Loading skeletons, error & empty states
- Links out to YouTube

## API
`https://api.freeapi.app/api/v1/public/youtube/videos`

## Stack
React 19 · TypeScript · Vite · Tailwind CSS v4

## Run
```bash
pnpm install
pnpm dev
```
