# Quote Gallery

A quotes browsing app powered by the [FreeAPI](https://freeapi.app) Quotes API.

## Features
- Quote card gallery with author and tags
- Copy-to-clipboard per quote
- Shuffle button (jumps to a random page)
- Debounced search & pagination
- Loading skeletons, error & empty states

## API
`https://api.freeapi.app/api/v1/public/quotes`

## Stack
React 19 · TypeScript · Vite · Tailwind CSS v4

## Run
```bash
pnpm install
pnpm dev
```
