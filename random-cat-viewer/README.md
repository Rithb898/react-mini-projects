# Random Cat Viewer

A random cat breed viewer powered by the [FreeAPI](https://freeapi.app) Random Cat API.

## Features
- Cat image with fade-in on load
- Breed name, temperament, description
- Origin / life-span / weight facts
- "New cat" button to fetch a fresh one
- Loading & error states

## API
`https://api.freeapi.app/api/v1/public/cats/cat/random`

## Stack
React 19 · TypeScript · Vite · Tailwind CSS v4

## Run
```bash
pnpm install
pnpm dev
```
