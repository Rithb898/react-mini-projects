# People

A random users UI powered by the [FreeAPI](https://freeapi.app) Random Users API.

## Features
- User card grid (avatar, name, username, gender & country)
- Profile modal: email, phone, cell, age, full address, nationality
- Debounced search & pagination
- Loading skeletons, error & empty states

## API
`https://api.freeapi.app/api/v1/public/randomusers`

## Stack
React 19 · TypeScript · Vite · Tailwind CSS v4

## Run
```bash
pnpm install
pnpm dev
```
