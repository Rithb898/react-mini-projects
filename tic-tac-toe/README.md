# Tic Tac Toe

A clean, interactive two-player Tic Tac Toe game built with React.

## Features
- 3×3 board with two-player turn system (X / O)
- Winner detection with highlighted winning line
- Draw detection
- Live scoreboard (wins + draws) that persists across rounds
- Reset / play-again control
- Current-turn and result status with Motion animations

## Stack
React 19 · TypeScript · Vite · Tailwind CSS v4 · Motion

## Run
```bash
pnpm install
pnpm dev
```
