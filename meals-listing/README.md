# MealBox

A meals / recipes listing interface powered by the [FreeAPI](https://freeapi.app) Meals API.

## Features
- Meal card grid (thumbnail, area badge, name, category)
- Detail modal: ingredients with measures, full instructions, tags, YouTube link
- Debounced search & pagination
- Loading skeletons, error & empty states

## API
`https://api.freeapi.app/api/v1/public/meals`

## Stack
React 19 · TypeScript · Vite · Tailwind CSS v4

## Run
```bash
pnpm install
pnpm dev
```
